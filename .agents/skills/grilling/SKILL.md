# Гриллинг

Без поблажек интервьюируй пользователя по каждому существенному аспекту плана, решения или идеи, пока не достигнете общего понимания.

## Процесс

1. Построй дерево решений и последовательно проходи по его веткам, разрешая зависимости между решениями одну за другой.
2. Задавай строго по одному вопросу за раз и жди ответа пользователя, прежде чем продолжить. Несколько вопросов одновременно только запутывают.
3. Вместе с каждым вопросом давай свой рекомендуемый ответ и коротко объясняй, почему рекомендуешь именно его.
4. Если факт можно установить, исследовав окружение — файлы, код, документацию или доступные инструменты, — установи его самостоятельно, а не спрашивай пользователя.
5. Решения оставляй пользователю: явно ставь каждое из них перед ним и жди ответа.
6. После каждого ответа учитывай принятое решение, обновляй следующие развилки и продолжай с ближайшей неразрешённой зависимостью.
7. Не уходи в ветки, которые не способны изменить решение или план.
8. Когда все существенные ветки пройдены, кратко изложи достигнутое понимание, открытые риски и принятые решения, затем попроси пользователя явно подтвердить, что общее понимание достигнуто.
9. До этого подтверждения ничего не реализуй и не меняй. Исследование разрешено; действия по воплощению плана — нет.

## Формат вопроса

```markdown
**Вопрос:** <один вопрос>

**Моя рекомендация:** <рекомендуемый ответ и краткая причина>
```
